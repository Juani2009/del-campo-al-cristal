LLT · NUEVA VERSIÓN: MEJORAS

1. INICIO SIN VISUAL STUDIO CODE
   Con Internet, extraé el ZIP y ejecutá PREPARAR_PRIMERA_VEZ.bat una sola vez.
   Para cada exposición: conectá primero la Lenovo a la red Wi-Fi local y hacé
   doble clic en INICIAR_CLARIFICADOR.bat. Dejá abierta la ventana negra.
   Se abre automáticamente http://localhost:4173/ con sala y QR.
   No hace falta iniciar el servidor desde VS Code.
   Si cambiás código más adelante: ejecutá npm run build para regenerar dist.

2. MODO INDIVIDUAL
   http://localhost:4173/?modo=individual
   También hay un enlace en la sala de espera. No necesita conectarse a otros
   dispositivos ni esperar grupos; cada persona elige las cuatro variables.
   Para mostrarlo por Internet en el futuro haría falta publicar la web individual.

3. CALIDAD GRÁFICA
   Modo equilibrado en PC, ligero en celulares. En modo individual hay selector.
   También se puede añadir ?calidad=ligera a la dirección grupal; por ejemplo:
   http://localhost:4173/?calidad=ligera
   Calidad alta con ?calidad=alta. La máquina y su recorrido son los mismos.

4. PANEL DE OBSERVACIÓN
   http://IP-DE-LA-LENOVO:4173/control
   Tu compañero puede mirar el panel desde otro celular, sin PIN, pero no
   puede iniciar, reiniciar ni cerrar votos desde esa vista.
   Para acciones especiales se requiere PIN (Opciones de presentadora).
   En la Lenovo, abriendo http://localhost:4173, el acceso de presentadora
   se autoriza automáticamente para iniciar la experiencia.

5. DESCONEXIONES
   Las estaciones abiertas se cierran tras 90 segundos si todavía quedan
   participantes sin votar. Se contabilizan únicamente los votos recibidos.
   Si una estación queda sin votos, se marca sin votos, sin ganador ficticio;
   puede requerir una decisión excepcional para completar el informe final.

6. ROUTER VS IPHONE
   Es el mismo procedimiento: conectar Lenovo y celulares al mismo Wi-Fi,
   reiniciar el servidor una vez cambiada la red y elegir IP para el QR.
   Un router apropiado no necesita Internet, pero debe proporcionar DHCP y
   permitir comunicación entre clientes. Comprobar capacidad para 20 equipos.

NOTA: Esta revisión NO incluye todavía un QR de conexión Wi-Fi, ya que se
necesita conocer el SSID y la contraseña de la red definitiva. El QR actual
abre la página de votaciones después de conectar el celular al Wi-Fi.
